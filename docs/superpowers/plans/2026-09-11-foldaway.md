# Foldaway 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 做一个菜单栏 app：合上 MacBook 盖子时内建屏幕内容从铰链远端开始逐渐变糊变暗，打开则恢复。

**Architecture:** 纯逻辑（曲线、平滑、预览时序、设置）放在 SwiftPM 包 `FoldawayCore` 里单测；App 层用 IOKit HID 读开合角，
用私有 `CABackdropLayer + CAFilter(variableBlur)` 在一个透明覆盖窗上做渐变模糊，`CAGradientLayer` 做压暗，
`CADisplayLink` 驱动每帧插值。

**Tech Stack:** Swift 5 语言模式（Xcode 26.5 工具链）、AppKit、QuartzCore、IOKit.hid、ServiceManagement、XCTest、xcodegen。

**Spec:** `docs/superpowers/specs/2026-09-11-foldaway-design.md`

## Global Constraints

- 最低 macOS 14.0；只盖内建显示器；不沙盒；不需要 TCC 权限。
- 曲线常量与参考 shader 一致：指数 1.35，压暗起点 0.2，压暗强度 2 倍封顶。
- 默认值：startAngle 85，endAngle 15，maxBlurRadius 48，start−end ≥ 15。
- 预览时序：1.4 s 合上，0.6 s 停，1.4 s 打开，smoothstep。
- 仓库目前不是 git 仓库；"Commit" 步骤在用户 `git init` 前跳过，改为把本文件的复选框勾上。
- 代码里不写解释性注释（守则 13）；私有 API 只通过字符串取类名和 KVC，不引私有头。

```swift
public enum FoldCurve {
    public static let blurExponent = 1.35
    public static let darkenExponent = 1.35
    public static let darkenStart = 0.2
    public static let darkenStrength = 2.0
    public static func smoothstep(_ t: Double) -> Double { let x = min(max(t, 0), 1); return x * x * (3 - 2 * x) }
    public static func motion(angle: Double, startAngle: Double, endAngle: Double) -> Double {
        guard startAngle > endAngle else { return angle < startAngle ? 1 : 0 }
        return smoothstep((startAngle - angle) / (startAngle - endAngle))
    }
    public static func blurWeight(edge: Double) -> Double { pow(min(max(edge, 0), 1), blurExponent) }
    public static func blurRadius(edge: Double, motion: Double, maxRadius: Double) -> Double { maxRadius * motion * blurWeight(edge: edge) }
    public static func darkenAlpha(edge: Double, motion: Double) -> Double {
        let gradient = min(max((edge - darkenStart) / (1 - darkenStart), 0), 1)
        return min(1, darkenStrength * motion * pow(gradient, darkenExponent))
    }
}
```
- [x] **Step 4: 测试全绿**
